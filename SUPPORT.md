# Getting help

- **Questions, ideas, "how do I…"**: ask on [Discord](https://discord.gg/gS6qtuShvw). It's the fastest way to reach people.
- **Something's broken**: open an issue in the repository it belongs to, using the bug report form.
- **A security problem**: report it privately. See [SECURITY.md](SECURITY.md).
- **Bricked a device?** Ask in Discord `#rescue-help`. Someone has probably been there before.
